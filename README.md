# AI-Powered QA Automation Framework

An evolving QA automation framework built with **Playwright and TypeScript**, designed to demonstrate modern UI automation, API testing, CI/CD integration, and AI-assisted test analysis.

## Project Overview

This project aims to build a practical, maintainable automation framework that improves test reliability, reduces repetitive QA effort, and provides useful insights into test failures.

## Tech Stack

| Technology | Purpose |
|---|---|
| Playwright | Browser automation |
| TypeScript | Automation development |
| Node.js | Runtime environment |
| Git & GitHub | Version control |
| GitHub Actions | CI/CD automation |
| API Testing | Service-level validation |
| AI Integration | Intelligent test failure analysis |

## Current Features

- Playwright initialized with TypeScript.
- Cross-browser execution: Chromium, Firefox, and WebKit.
- Sample automated test suite.
- Playwright HTML reporting.
- GitHub Actions workflow configuration.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Mohammed-Abrar-Shaikh/ai-powered-qa-framework.git
```

Navigate to the project:

```bash
cd ai-powered-qa-framework
```

Install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

### Execute Tests

```bash
npx playwright test
```

### View HTML Report

```bash
npx playwright show-report
```
